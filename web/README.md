# Chronomap web app

This is Chronomap's static, responsive demonstration SPA. It reads the public
bundle at `/data/synthetic/`; that bundle is a non-historical demo generated by
the Python public-bundle builder, not a record of real history.

## Setup and commands

From this directory, install Node dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production static build:

```sh
npm run build
```

Run the unit tests or Chromium browser acceptance tests:

```sh
npm test
npm run test:browser
```

The browser tests run both 390×844 smartphone and 1440×900 desktop projects.
Install Playwright's Chromium browser if it is not already available with
`npx playwright install chromium`.

## Demo data

The five checked-in public files under `public/data/synthetic/` are generated
with the repository's Python builder:

```sh
cd .. && uv run chronomap-data build-public tests/fixtures/valid/synthetic-package --output web/public/data/synthetic
```

Only those public projection files are served to the browser. Authoring data,
including private feature versions and source body text, is not copied here.
