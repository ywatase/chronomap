# Chronomap プロダクトロードマップ

## 実装済みパイロット: 授業用に教材を整える

既存のガイド教材を、カタログまたは教材の開始・完了画面から授業用に整えられる。教員は教材のタイトル、対象・クラス、観察の問い、教員用参照資料の表示、既存のステップを入力・選択してプレビューし、印刷できる。`view=builder`の直接アクセスにも対応する。対象は静的パイロットであり、作成内容はブラウザ内だけで扱い、再読み込み時には破棄される。

今回の非目標は、認証、ログイン、保存、共有された教材編集、課金、契約管理である。既存の日本語化、UIテスト、Playwright E2E、レスポンシブUIとUI/UX改善は継続して保持・拡充する。

## 続く工程

- 実データセットと出典・不確実性の追加
- 静的公開品質、スクリーンショット確認、E2Eの拡充
- 保存・認証などの教員ワークフローは、パイロットの利用検証後に別途判断する
