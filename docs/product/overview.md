# Chronomap プロダクト概要

作成日: 2026-09-14

## 目的

Chronomapは、歴史上の地物・政治的領域を現在の地図と時代を切り替えながら比較できる地図プロダクトである。出発点となった要望は[原文](../original/first_prompt.txt)に保存する。現在の地形だけでは理解しにくい水運、海岸線、湖沼、河川、城郭、集落、港、古戦場、国、勢力圏の関係を、出典をたどれる歴史データとして提示する。

## 利用者とビジョン

主利用者は、歴史地理に関心を持つ一般の歴史愛好家である。日本史・地域史を学ぶ学習者、教員、郷土史の調査者は、副次的利用者の例として想定する。将来は中国史と世界史にも広げるが、単一の共通Webアプリに地域別データセットを追加し、時代ごとの地理的な変化を比較・検証できる基盤にする。

## MVPの範囲

MVPはJapan-firstとし、巨椋池周辺を深掘りする。背景地図に対し、時代を選択して歴史データを重ね、地物を選ぶと名称、説明、対象年代、確度・不確実性、出典を確認できることを最小機能とする。

検証に必要なデータは次のとおりである。

- 点: 城郭、港、集落、史跡などの地点
- 線: 河川、水路、街道、境界などの線状地物
- 面: 巨椋池、海岸線、勢力圏、国などの領域

成功条件は、利用者が巨椋池周辺の複数時代を切り替え、現在の地図と比較し、各表示の出典と不確実性を確認できることである。

## 原則と非目標

今回のMVPは、中国史・世界史のデータ制作、全地域の完全性、ログイン、単独ユーザーを含むブラウザ上の編集、リアルタイム共同編集、サーバーAPI、ネイティブアプリを目標にしない。歴史情報を創作せず、根拠を示せない内容を事実として表示しない。出典と不確実性を各データに結び付ける。

データとコードは分離し、地域ごとの拡張はデータセットの追加で行う。重要なドメインロジックはテスト可能な形で実装し、年代判定やデータ検証を重点的にテストする。採用する構成は[アーキテクチャ概要](../architecture/overview.md)と[ADR](../adr/README.md)で定義する。

## 承認後のロードマップ

基礎文書、データ契約、UI設計、巨椋池の小規模な公開データ接続、初回の日本語化、レスポンシブUI、Playwright導線、共有可能な歴史ビュー、同一地物の2時点比較は実装済み。次は、実データの追加とスクリーンショット確認を含む公開品質を段階的に高める。

1. **データ制作（完了・継続）**: 巨椋池周辺の4地物バージョン（点・線・面）を、出典、locator、不確実性、権利とともに制作・検証し、`validate → build-public → Web UI` に接続した。次の地物追加も同じ境界を守る。
2. **日本語化（初回完了）**: Datasetの既定言語を日本語にし、年操作、一覧、詳細、出典、権利、失敗・再試行状態、アクセシビリティ名を日本語化した。英語データのフォールバックも維持している。
3. **UIのPlaywright E2Eテスト（初回完了・拡充継続）**: 390×844と1440×900で、収録年の切替、一覧・詳細、キーボード操作、データセット失敗、背景地図失敗・再試行を実ブラウザで固定した。
4. **UI/UX改善（初回完了・拡充継続）**: 地図中心のデスクトップ、モバイルの地図＋下部一覧／詳細、44px操作領域、bbox自動ズーム、初期・詳細・失敗状態のスクリーンショット取得を追加した。
5. **静的公開・CI整備（初回完了・拡充継続）**: 公開バンドル生成、Web build、unit/E2E、Python検証に加え、production previewへの直リンクSmoke TestをGitHub Actionsで再現できるワークフローを追加した。次は実ホスティング環境でも同じクエリ付き導線を監視する。収録範囲、比較・教材機能はデータ追加に合わせて進める。

6. **共有可能な歴史ビュー（完了）**: Dataset、年代、公開FeatureVersion、地図の中心・ズームを静的ホスティング互換のクエリに正規化し、直接アクセス・reload・ブラウザ共有／Clipboardに対応した。不正なURL入力は公開バンドルに照合して安全に既定値へ戻す。

7. **同一地物の2時点比較（初回完了・拡充継続）**: 同じEntityに属する公開・単年・確定スナップショットを自動導出し、宇治川1590年／1596年を1枚の地図上でワンタップ比較できるカードを追加した。比較側の選択は年代、一覧、詳細、共有URLに同期する。任意年代の比較、分割地図、同時オーバーレイは今後の検討とする。

8. **歴史地図レポート（初回完了・拡充継続）**: 選択した公開地物を、表示年、可能期間、説明、4次元の不確実性、根拠のlocator、出典、権利、共有URLとともに印刷用DOMへ投影し、ブラウザの印刷／PDF保存へつなげた。背景地図取得に失敗しても文章と根拠は出力できる。複数時点の一括レポート、教材用ワークシート、高解像度出力は今後の候補とする。

9. **表示設定と凡例（初回完了）**: 地図上の表示パネルから背景地図と歴史地物の濃さを個別に調整し、歴史地物の表示／非表示を切り替えられるようにした。点・線・面・選択中の4項目を色だけに依存しない凡例で示し、設定は背景地図の再試行後も維持する。
10. **ガイド教材（初回実装）**: 既存の年代切替、比較カード、詳細、共有、レポートを4ステップ・約15分の静的教材へ束ねた。`lesson` と `step` を共有URLに含め、直接アクセスとreloadで同じステップへ戻れる。教材マニフェストは公開地物・年代・比較対象を起動時に検証し、不正または欠落時は通常の地図表示へ戻る。採点、ログイン、外部本文・画像の転載は行わない。
11. **授業用教材パック（β版初回実装）**: 教材完了時に、生徒用ワークシート、教員用参照資料、出典・権利一覧をA4縦の印刷用DOMへまとめ、ブラウザのPDF保存へつなげた。各ステップの共有URL、観察問い、記入欄、不確実性、Evidence locator、Sourceの権利を含む。restricted Sourceは引用メタデータだけを表示し、原資料本文・画像・碑文は転載しない。β版中は無料で試せることと、将来の地域別教材・教員向け一括出力を候補として示す。利用時の授業ニーズは、次のデータ制作と教材改善で検証する。
12. **第2データセット（初回実装）**: 静的なallow-listカタログから「利根川東遷」データセットへ切り替えられるようにした。1590年頃の東遷前概略線、1594年の川俣締切地点、1654年の東遷後概略線を、出典・不確実性・権利付きの2 Entity／3 Featureで提供する。`dataset`付きURL、比較、3ステップ教材、教材パックを同じWebアプリで復元できる。形状は精密な河道・施設位置ではなくChronomapの概略復元に限定し、外部資料の本文・図版は転載しない。

13. **地域・教材カタログ（初回実装）**: ヘッダーの単一導線から、allow-list済みの全データセットを地域、収録年、公開地物・歴史対象・出典数、教材時間・ステップ数とともに確認できるようにした。利用可能なカードだけに「無料デモ」「教材パックはβ版無料」の導線を表示し、地図・ガイド教材の開始URLを生成する。`view=catalog`で直接アクセス・reloadでき、片方の公開バンドルが失敗しても他カードを利用できる。価格・契約・課金状態は断定せず、無料機能と将来の教員向け候補を分けて示す。

14. **第3データセット（平城京パイロット）**: 平城京・平城宮・朱雀大路の都市軸を、710年の3地物バージョンとして追加した。奈良市の公式解説は引用メタデータに限定し、地図形状はChronomapの粗い`original-reconstruction`として公開する。`dataset=heijokyo`、3ステップ教材、教材パック、地域・教材カタログ、デスクトップ／スマートフォンのE2E導線を同じ静的アプリで復元できる。正確な都城境界・道路線形・未確認の河川は主張しない。

進行順は、まず小規模な実データ制作を行い、そのデータを使って日本語化とE2Eを確認し、最後にスクリーンショットベースのUI/UX改善とCI整備を行う。PMTiles、サーバーAPI、編集機能は、データ量や運用要件が静的MVPの範囲を超えた時点で別途判断する。
