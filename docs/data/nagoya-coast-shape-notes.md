# 名古屋・伊勢湾奥の海岸線 形状作成メモ

作成日: 2026-10-17

このメモは、`data/nagoya-coast/feature-versions.geojson` の4つの概略面をどう作ったかを記録する。各面は「その時代に海だった範囲」で、ビューアーは `display.seaMask` により背景地図の海の色で塗る。南端は伊勢湾内（北緯34.96度）で切っており、そこから南は現代の地図の海と同じである。江戸末期〜明治初期は全国の『江戸末期海岸線／水域データセット』（[edo.md](edo.md)）が表示する。

## 参照した資料

- 環境省中部地方環境事務所『伊勢・三河湾流域における土地の履歴』p.3 図2「濃尾平野の各時代の推定海岸線」（出典: 上田篤・中村良夫・樋口忠彦『日本人はどのように国土をつくったか』）。縄文前期・縄文中期・弥生・古墳後期の海岸線と近世以降の干拓地を示す。書籍からの転載図なので、引用メタデータだけを記録し、図をトレース・転載していない。図の解像度は低く、海岸線の位置は地名ラベル（大垣・岐阜・一宮・名古屋）と河川からの相対位置として読んだ。
- 同 p.6 本文・図9「伊勢湾の開拓」。名古屋市熱田区・港区・中川区・南区の一部、弥富町・十四山村・飛島村・木曽岬町が江戸時代の干拓で形成されたこと（約5,000ha）。
- 環境省中部地方環境事務所『藤前干潟の歴史』。江戸時代初期の海岸線は東海道（現在の国道1号）付近、後期には国道23号付近まで干拓が進んだという記述。
- 名古屋市『名古屋のまちの成り立ち』p.7。縄文前期の海岸線が名古屋台地に沿って「ゾウの鼻」のような形だったこと。
- 基準点: 国土地理院の住所検索で得た大垣・墨俣・羽島・一宮・岩倉・西春・清須・甚目寺・七宝・津島・佐屋・岩塚・名古屋城・熱田・笠寺・星崎・鳴海・大高・戸田・蟹江・弥富・立田・桑名・多度・養老・輪之内の代表点。

## 作成方法

- 縄文前期（代表年 紀元前4000年）: 北縁を大垣・墨俣・羽島の南、一宮の南、岩倉・西春の西に置き、名古屋台地の西縁に沿って熱田まで下げた。熱田台地の東側にも海が入り、瑞穂・笠寺・鳴海・大高付近まで入り江が回り込む形（ゾウの鼻）にした。西縁は養老山地の東麓（養老・多度）とした。縄文中期の線（図2の破線）は収録していない。
- 弥生時代（代表年 紀元前100年）: 図2の弥生時代の海の北限を、輪之内・稲沢の南から甚目寺・清須付近を結ぶ線として置いた。熱田台地東の入り江は縄文前期より狭くした。
- 古墳時代後期（代表年 550年）: 図2の古墳時代後期の海岸線北限を、佐屋・津島・七宝・大治・岩塚の南を結ぶ線として置いた。熱田台地東の年魚市潟（あゆちがた）は笠寺・鳴海付近まで残した。
- 江戸初期（1600年、1700年まで表示）: 『藤前干潟の歴史』の「東海道（国道1号）付近」に従い、熱田から中川区南部・戸田・蟹江・弥富・立田の南を結ぶ線とした。17世紀以降の前期干拓で南へ広がるため、可能期間の終わりを1700年頃とし、それ以降は江戸末期データ（1800年〜）までの間を参考表示に任せる。
- すべて少ない頂点の概略で、入江・干潟・河口・島（長島などの輪中）の形は表さない。頂点の小数桁は精度を意味しない。数km程度ずれうる。

## 採用しなかった資料と主張

- 「尾張太古之図」（養老元年・717年とされる）は、古代の海岸線を桑名・大垣・岐阜・犬山・小牧・緑区を結ぶ線とするが、伝承的な絵図で地形学の推定海岸線と合わないため形の根拠にしていない。
- 縄文中期の海岸線、干拓の前期・中期・後期の各段階（図9）は、位置を十分に読み取れないため収録していない。
- 資料の図・本文を再現していない。形を作成したのはChronomapであり、環境省・名古屋市・書籍の著者がこのGeoJSONを作成したものではない。
