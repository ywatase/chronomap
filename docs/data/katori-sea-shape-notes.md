# 香取海 形状作成メモ

作成日: 2026-10-19

香取海の水域は、現在の地形に残る低地を標高から抽出し、外洋との連結を判定した上で、資料図との比較に基づく場所別の補正を加えたモデル推定である。標高は形状の下地であり、過去の標高・水深・海岸線を直接計測したデータではない。

## 作図条件

対象範囲は東経139.95〜140.95度、北緯35.65〜36.25度。DEM5aを優先し、ないタイルはDEM10bへ切り替える。ズーム13が欠ける場合のみDEM10bのズーム12タイルを補助に使う。外洋seedにはGSI住所検索で得た`千葉県銚子市川口町`の緯度の行だけを使い、同住所の経度から東側で最も右にある取得済みDEM欠測セルを選ぶ。bboxを覆う完全なタイルモザイク全域で、閾値以下のセルを4近傍で探索する。取得不能タイルは海に含めない。面化後に地理bboxと外洋カットで切る。面境界はWeb Mercatorのメートル座標で作り、100mで簡略化してからWGS84に変換する。面積1ha未満の穴と断片を落とす。孤立した湖・低地は海に含めない。標高から得たマスクに、資料比較で根拠を確認した補正だけを加える。

| 表示年 | 初期閾値 | 表現 |
| ---: | ---: | --- |
| 700 | 4m | 古代の代表的な内海の推定 |
| 1200 | 3m | 中世の代表的な内海の推定 |
| 1600 | 2m | 利根川東遷・新田開発期の推定。FeatureVersionは1654年まで |
| 1700 | — | 香取海マスクなし。1654年の利根川東遷完了後の比較用表示 |

## 限界と採用しなかった主張

- この形状は水深・潮位・潮間帯・旧汀線・個々の河道中心線を復元しない。
- 地表標高は現代の盛土、堤防、湖岸堤、浚渫、干拓、埋立後の地形である。標高だけで当時の境界を断定しない。
- 700年、1200年、1600年は代表時点であり、閾値とFeatureVersionの年代幅は資料の正確な測量時点を意味しない。
- 千葉県立中央博物館・香取市・国土交通省の図を複製・トレースしていない。採用しなかった旧版形状、町村境界、細かな水路、地名ごとの領域、海水遡上限界は主張しない。
- 1700年は香取海の年代範囲外とし、近世以降の霞ヶ浦等を一続きの海として表示しない。

## 比較画像と所見

DEM下地のみを700年4m・1200年3m・1600年2mで生成し、香取市Vol.208の模式図と同じbboxの画面に並べて確認した。模式図は地理位置合わせせず、形のつながりを比較した。高地の住所基準点（土浦大岩田11.09m、行方玉造30.34m、印西師戸5.19m、我孫子高野山18.90m、犬吠埼24.12m、鹿嶋宮中38.05m）はいずれの下地にも入らず、台地を海にする旧版の誤りを避けられている。

下地は霞ヶ浦・北浦・印旛沼・手賀沼側へ伸びる低地のまとまりを示し、閾値を4m→3m→2mへ下げるにつれて面積が縮んだ。一方、銚子以東の標高タイルNoDataを海面として扱うため、鹿島灘・銚子沖の外洋が下地に広く含まれた。また、銚子川口町のGSI住所点（3.75m）は3m・2m閾値より高く、1200年・1600年の下地で銚子口が切れた。香取市の模式図と国交省の流路変更資料は、内海が銚子側で太平洋とつながる配置を示すため、以下の補正を加える。

| 地名・対象 | 年代 | 操作 | 補正 | 理由・根拠 |
| --- | --- | --- | --- | --- |
| 鹿島灘・銚子沖の外洋側 | 700 / 1200 / 1600 | 除外 | bbox内の保持側を`(139.95,35.65) → (140.95,35.65) → 犬吠埼 → 銚子市川口町 → 鹿嶋市宮中 → (140.640121,36.25) → (139.95,36.25)`の概略面とし、その外を除く | Vol.208模式図と国交省の東遷資料は香取海を内海として示す。カット線は現代住所アンカーとbboxをつないだモデル境界で、古海岸線の測量値ではない |
| 銚子口 | 1200 / 1600 | 追加 | 銚子市川口町のGSI住所点からDEM下地の最寄り境界までをつなぐ幅300mの回廊を加える。700年は4m下地が住所点まで達するため追加しない | 1200年・1600年下地と住所点の差は約73m・117m。香取市・国交省資料にある銚子側の太平洋接続を残す。幅300mは表示用の推定で、当時の河幅の測量値ではない |

位置合わせ基準と外洋seedには、県名・市名を含めた国土地理院住所検索APIの応答だけを使った。座標は前掲の基準点表にある値を使い、推測した地点を追加していない。
