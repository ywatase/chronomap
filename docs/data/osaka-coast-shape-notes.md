# 大阪湾奥・河内湖 形状作成メモ

作成日: 2026-10-17

このメモは、`data/osaka-coast/feature-versions.geojson` の概略面をどう作ったかを記録する。「大阪湾・河内湾の海」（海岸線、`display.seaMask` で背景地図の海の色で塗る）と「河内湖」（湖沼）の2つの歴史対象を、時代ごとの版で持つ。南端・西端は大阪湾内（東経135.38度、北緯34.56度）で切っている。江戸末期〜明治初期は全国の江戸末期海岸線・湖沼データ（[edo.md](edo.md)）が表示する。

## 参照した資料

- 国土交通省近畿地方整備局 淀川河川事務所『淀川の成り立ちと人とのかかわり』。本文「約7000〜6000年前の縄文時代前期の大阪平野は…河内湾と呼ばれた海の底にあり、現在の上町台地は半島のように突き出ていた」「河内湾は大阪湾と切り離されて河内潟へ、約2000年前以降の弥生時代中期には、淡水化し河内湖となりました」と、縄文中期・弥生中期の図（松田順一郎氏原図）、中世の河川図（深野池・新開池）。図は第三者の原図を含むため引用メタデータだけを記録し、トレース・転載していない。
- 水都大阪コンソーシアム『古代大阪の変遷』（出典: 大阪ブランド資源報告書）。約7000〜6000年前の水面が「東は生駒山麓、南は八尾、北は高槻付近まで」、現在の松屋町筋付近に砂浜、約1800〜1600年前に天満・長柄の砂州が延びて淡水湖になったという記述。作成時の読み取りに使い、公開Evidenceには含めていない。
- 大阪府『大阪広域ベイエリアまちづくりビジョン（素案）』、大阪市『大阪港の景観特性をとらえる要素・歴史』（旧 `data/osaka` から引き継いだ引用）。
- 基準点: 国土地理院の住所検索で得た大阪城・松屋町・上本町・天王寺・住吉大社・堺・天満・長柄・十三・伝法・九条・木津・津守・尼崎・吹田・摂津・茨木・高槻・枚方・交野・寝屋川・四條畷・門真・守口・深野・住道・鴻池新田・放出・森河内・布施・若江・八尾・久宝寺・平野・石切・枚岡・柏原の代表点。

## 作成方法

- 縄文前期〜中期（代表年 紀元前4000年）の海: 上町台地の西縁（堺・住吉・天王寺・松屋町）を海岸とし、台地北端（大阪城の北）を回り込んで東縁を南へ下げ、八尾付近を南限、生駒山麓（枚岡・石切・四條畷）を東限、枚方・高槻付近を北限、千里丘陵の南（吹田・摂津・茨木の南）を北岸とした。上町台地は陸として残る。
- 弥生中期（紀元前100年）: 海は上町台地の西側に残り、北端は天満〜長柄の砂州、十三・神崎川河口付近を北岸とした。河内湖は上町台地の東麓から生駒山麓まで、北は門真・寝屋川、南は布施・若江付近の概略面とした。
- 古墳〜古代（500年）: 淀川河口の堆積で海岸線をやや西へ下げ、河内湖を縮小させた（草香江）。
- 中世〜江戸初期（1600年、1704年まで表示）: 海岸線を住吉・津守・木津・九条・伝法の西とした。河内湖の名残を深野池（深野・住道の北）と新開池（鴻池新田付近）の2つの小さな面とし、大和川付け替え（1704年）で終わる。
- すべて少ない頂点の概略で、砂州・三角州・河道・島は表さない。数km程度ずれうる。

## 採用しなかった主張

- 縄文中期・弥生前期など、図に描かれていても年代や位置を十分に読めない段階は収録していない。
- 九条島・安治川（1684年）・新田開発の各段階は収録していない。
- 形を作成したのはChronomapであり、国土交通省・大阪府・大阪市・原図の作成者がこのGeoJSONを作成したものではない。
