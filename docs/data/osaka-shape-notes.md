# 大坂・石山本願寺パイロットの形状メモ

このパッケージの古代・中世 geometry は、資料に書かれた地形・位置関係を読みやすくするための概略復元です。行政境界、古代の海岸線、寺域、港域、河道中心線を確定するデータではありません。

## 参照した資料

- [大阪府「大阪広域ベイエリアまちづくりビジョン（素案）」](https://www.pref.osaka.lg.jp/documents/2275/0520shiryou1-2_2.pdf)：大阪湾・河内湾・河内湖の形成と水域変化を読む根拠。
- [大阪市「大阪市の歴史－タイムトリップ20,000年（飛鳥・奈良時代以降）」](https://www.city.osaka.lg.jp/seisakukikakushitsu/page/0000010252.html)：上町台地、淀川・大和川の水運、渡辺津の位置関係を読む根拠。
- [大阪市「大阪港の景観特性をとらえる要素・歴史」](https://www.city.osaka.lg.jp/port/page/0000432129.html)：古代大阪で上町台地が半島のように突き出し、その東側に河内湖が広がったという相対関係を読む根拠。
- [大阪市中央区「石山（大坂）本願寺推定地」](https://www.city.osaka.lg.jp/chuo/page/0000641506.html)：1533年の開山、濠・土居に囲まれた寺内町、1580年の退去を読む根拠。

## 手作業で置いた座標と限界

- 石山本願寺は、現在の大阪城周辺にあたる位置を代表 Point として置いた。寺域、濠、土居の精密な境界を描いていない。
- 石山合戦は、同じ本願寺推定地の代表 Point を戦場コンテキストの読み取りに再利用した。戦場全体、砦、陣地、戦線、行軍路の精密な位置・範囲ではなく、`fortification`の本願寺代表点とは歴史的意味を分けて表示する。
- 寺内町は、上町台地北端の集住・活動域を読むための低頂点 Polygon とした。町割、屋敷、道路、境界を再現していない。
- 渡辺津は、公式説明の「天満橋から北浜南岸」という相対位置を代表 Point に置いた。港域、岸線、船着場、航路の精密位置ではない。
- 淀川水運は、大阪から淀川上流へ向かい京都につながる関係を読むための概略 LineString とした。歴史的な河道中心線、航路、距離ではない。

## 古地図・空中写真タイルとの分離

データセットの `ort_riku10` は、[地理院地図タイル一覧](https://maps.gsi.go.jp/development/ichiran.html) に記載された1936〜1942年頃の陸地測量部空中写真タイルである。古代・中世の geometry や当時の境界を示す資料ではなく、後世の地理コンテキストとして別レイヤーに表示する。利用時は[地理院地図の利用規約](https://maps.gsi.go.jp/help/termsofuse.html)と出典表示に従う。

## 2026-10-17 河内湾・河内湖の移動

古代の河内湾・河内湖の概略面と古代海岸線の線は、時代ごとの版を持つ `data/osaka-coast`（[作成メモ](osaka-coast-shape-notes.md)）に置き換えたため、このパッケージから外した。大阪府・大阪市の2資料の引用はそちらへ引き継いだ。
