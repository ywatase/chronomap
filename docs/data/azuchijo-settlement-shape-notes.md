# 安土城下町推定範囲形状作成メモ

滋賀県の安土城跡周辺資料は、安土城築城に伴う城下町跡（推定）の範囲を、活津彦根神社から南腰越峠に至る一帯などとして説明しています。この説明は、城下町の街区、屋敷、道路、集落境界を測量したGeoJSONや、1576年時点の確定した都市面を提供するものではありません。

## 表示方法

`azuchijo:version:azuchi-settlement-1576` は、安土山・城下町・常楽寺湊の相対関係を地図上で読むための低頂点Polygonです。公開資料の推定範囲と安土城の位置関係を少数の頂点へ置き換えたChronomap独自の概略復元であり、行政境界、町割、屋敷地、道路、遺構の精密な範囲ではありません。

表示期間は安土城築城開始から本能寺の変までの1576〜1582年頃です。城下町の前史、廃城後の町の移転、現在の市街地はこのFeatureVersionへ含めません。

外部資料の本文・図版・地図画像は再配布せず、SourceとEvidenceの引用メタデータだけを保持します。
