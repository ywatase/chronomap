# 江戸末期の海岸線・湖沼の取込

作成日: 2026-10-17

背景の現代地図は、埋立・干拓後の海岸線と湖沼を描く。江戸時代以前の年を見るときに現代の地形が当時の姿のように見えないよう、`chronomap-data import edo` でCODHの全国データから江戸末期〜明治初期の海と湖沼を取り込む。

| 資料 | 内容 | 使い方 |

| 『江戸末期海岸線／水域データセット』（ROIS-DS人文学オープンデータ共同利用センター作成）doi:10.20676/00000453 `coast-polygon.zip` | 輯製二十万分一図（1884〜1894年）を基に、伊能大図で修正した江戸末期〜明治初期の陸地ポリゴン（全国） | 陸地の外側約8kmまでを「当時の海」の帯にする（パッケージ `edo-coast`） |
| 『江戸末期湖沼データセット』（同）doi:10.20676/00000467 `lake_polygon.geojson` | 1800年頃以降に消滅・部分干拓・拡張した湖沼573件の推定湖面。名称・参照資料を備考に持つ | 湖沼ごとに1地物（パッケージ `edo-lakes`） |

## 期間

江戸末期〜明治初期のスナップショットとして、可能期間を `start: {1800, 1868}`、`end: {1868, 1894}`（`precision: period`、`qualifier: circa`）とし、1800〜1894年に表示する。湖沼・海岸線なので、それより前の年は「最古の版の参考表示」（[タイル契約](tiles.md)）で表示する。1895年以降は表示しない（干拓竣工年は備考にある湖沼もあるが、今回は使わない）。

## 「当時の海」の帯と表示

陸地ポリゴンを融合し、外側へ約8km（0.08度）広げた範囲から陸地を除いた帯を、1つのMultiPolygonとして持つ。Datasetの `display.seaMask` を `true` にすると、ビューアーはこの帯を背景地図の海の色（淡色・標準地図は `#bed2ff`、写真は `#10142f`、背景の濃さに合わせて混色）で不透明に塗る。現代も海の場所は見た目が変わらず、現代は埋立地・干拓地の場所だけが当時の海として見える。帯の外（沖合8km以遠）は現代の地図のままである。

## 限界

- 輯製二十万分一図と伊能大図の縮尺（基本は20万分の1）の精度で、細かな入江・河口・干潟は表せない。
- 江戸末期の一時点であり、近世初期の海岸線（名古屋・大坂などの新田開発前）は地域別のデータ（ロードマップのD）で補う。
