# 利根川東遷パイロット形状作成メモ

作成日: 2026-09-18

`data/tonegawa/feature-versions.geojson` の形状は、利根川東遷を比較するためにChronomapが現在のWGS84地図上で作成した概略復元である。精密な河道中心線、事業区域、締切施設の位置・形状を表さない。

## 参照資料

- 国土交通省「利根川水系河川整備基本方針（概要）」と「利根川（日本の川）」を、東遷事業と水系の説明を確認する引用メタデータとして用いた。
- 埼玉県「埼玉県の文化財」を、会の川締切に関する説明の確認に用いた。
- 外部資料の本文、図版、地図画像、座標を転載・トレースしていない。

## 作成方法と限界

- 1590年と1654年のLineStringは、資料が示す東遷前後の相対的な流路関係を少数の折れ点で表した。年の間の流路を補間しない。
- 1594年のPointは会の川締切を比較するための代表位置であり、施設位置や工事範囲を確定しない。
- 全形状はChronomapの`original-reconstruction`であり、国土交通省または埼玉県が作成・承認したGeoJSONではない。
