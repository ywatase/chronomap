# 鬼怒川・小貝川河道変遷パイロット形状作成メモ

作成日: 2026-10-03

このパイロットは、国土交通省関東地方整備局と国土地理院が公開する河川概要・河道変遷の説明を、現在地図上で比較できる概略表現へ置き換える。外部資料の本文、図版、航空写真、旧版地形図、原資料の座標は転載・トレースしない。

## 参照資料

- 国土交通省「日本の川・鬼怒川」を、鬼怒川の水源、南流、利根川への合流という水系関係の確認に使う。
- 国土交通省関東地方整備局「鬼怒川・小貝川の歴史（治水）」を、768年の流路開削と1629年の分離に関する引用メタデータとして使う。
- 国土地理院「鬼怒川の河道変遷（旧版地形図と米軍写真による把握）」を、旧版地形図・米軍写真から河道変遷を把握できることの確認に使う。画像や図版は再現しない。

## 作成方法と限界

- 768年と1629年のLineStringは、資料に記載される河道の接続関係を少数の折れ点で示した概略復元であり、旧河道の全区間、河道幅、工事区間、自然堤防を復元しない。
- 2020年のLineStringは、公式河川概要の水源・南流・利根川合流を現在地図上の相対関係へ置き換えた概略線であり、現況河道中心線ではない。
- 1629年のPointは分離事業の比較用代表点であり、施設・工事区間・史跡の精密位置ではない。
- 年代の間の流路を補間しない。古地図・旧版地形図・米軍写真の画像は公開bundleへ含めない。

したがって、表示は「鬼怒川の正確な旧河道図」や「1629年の工事図」ではない。詳細な位置・地形・原典画像は出典リンク先で確認する。
