# 賤ヶ岳古戦場代表点形状作成メモ

長浜市の歴史文化基本構想は、余呉湖の周辺から木之本・柳ヶ瀬に至る賤ヶ岳城塞群と古戦場を、1583年の羽柴秀吉・柴田勝家の戦場として説明しています。資料が示すのは広い戦場と複数の砦・史跡の関係であり、単一の確定した戦線や戦場境界のGeoJSONではありません。

## 表示方法

`azuchijo:version:shizugatake-battlefield-1583` は、賤ヶ岳古戦場を読み始めるための代表Pointです。余呉湖周辺の賤ヶ岳付近へ少数座標で置いたChronomap独自の概略復元であり、戦場全体、陣地、砦、行軍路、交戦範囲、史跡の個別位置を確定しません。

表示年は天正11年（1583年）の賤ヶ岳の戦いです。安土城下町や安土城を中心とする政治中枢とは別の、近江北部の古戦場コンテキストとして扱います。

外部資料の本文・図版・地図画像は再配布せず、SourceとEvidenceの引用メタデータだけを保持します。
