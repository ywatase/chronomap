# 余呉湖歴史文脈形状作成メモ

滋賀県の余呉湖資料は、余呉湖が賤ヶ岳によって琵琶湖と隔てられた自然湖であり、余呉川の水利用と周辺地域の地形に関わることを説明しています。資料は現在の湖の管理・地理的文脈を示すもので、1576年や1583年の水面、過去の湖岸線、湖底、堤体を測量した歴史GeoJSONではありません。

## 表示方法

`azuchijo:version:yogo-lake-1576` は、安土城・賤ヶ岳古戦場・余呉湖の位置関係を地図上で読み始めるための低頂点Polygonです。公開資料の現在位置と周辺地形を少数の頂点へ置き換えたChronomap独自の概略復元であり、歴史的な湖岸線、湖面積、水深、堤体、水位、治水施設の精密な復元ではありません。

表示期間は安土城の築城開始から賤ヶ岳の戦いまでの教材上の文脈（1576〜1583年頃）です。余呉湖自体の形成・利用史をこの期間に限定したり、1583年の水面を確定したりしません。

外部資料の本文・写真・図版・地図画像は再配布せず、SourceとEvidenceの引用メタデータだけを保持します。
