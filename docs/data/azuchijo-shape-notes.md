# 安土城・琵琶湖東岸パイロット形状作成メモ

このパイロットは、滋賀県と近江八幡市観光物産協会の公開ページが示す「安土城は安土山にあり、琵琶湖東岸の安土付近に位置する」という相対関係を、地図上で比較するための概略表現へ置き換える。

- 安土城と安土山は同じ代表点（`136.139, 35.155`）で表示する。これは所在地の相対関係を示すための点であり、城郭・山域・天主の境界や精密な測量点ではない。
- 琵琶湖東岸は安土の西側にあることを確認するため、少数の頂点を持つ概略線として表示する。現在・過去の湖岸線、埋立地、湖面変化を復元しない。
- 1576年・1579年・1582年の安土城の点は、同一代表点に置き、築城開始・完成・主郭部焼失という時間的な出来事の比較に限定する。焼失範囲や建物配置を geometry から推測しない。
- 安土城と琵琶湖東岸を結ぶ水運コンテキストは、湖岸拠点と移動・物資輸送の関係を考えるための直線的な概略接続線で表示する。実際の航路、港、船着場、船の位置や距離を復元しない。
- 形状は外部資料の本文、写真、図版、地図画像を再配布せず、公開メタデータとChronomapの独自概略復元だけで構成する。

したがって、表示は「当時の正確な城郭図」や「歴史的な湖岸線」ではない。詳細な位置や復元を必要とする場合は、出典リンクを開いて原資料と現地案内を確認する。
