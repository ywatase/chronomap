# 安土城・近江支配の拠点網 Polygon 作成メモ

この形状は、滋賀県『信長の城と戦国近江』が説明する「琵琶湖岸の拠点城郭から近江全体を支配する」という歴史的文脈を、地図上で検証するための概略表現である。

- Polygon は、琵琶湖岸の拠点城郭が近江各地へ配置された関係を囲むための少数の頂点で作成した。行政区画、近江国の正確な国境、城ごとの知行範囲、軍事的な実効支配線を復元しない。
- 1576〜1582年頃という期間は、安土城の築城開始から本能寺の変までを、信長を中心とする近江支配の拠点網を考えるための概略期間として置いた。各年の境界や支配の強度を示すものではない。
- `hypothesisGroupId` と `hypothesisLabel` により、確定した一つの国境ではなく、資料の記述を空間的に考えるための仮説であることを保持する。
- 外部資料の本文、図版、地図画像は再配布せず、引用メタデータとChronomapの独自概略復元だけを公開する。

したがって、この Polygon は「織田信長の勢力圏を正確に描いた図」ではない。詳細な領域境界を必要とする場合は、出典PDFと関連する城郭調査資料を原資料として確認する。
