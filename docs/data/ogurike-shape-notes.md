# 巨椋池パイロット形状作成メモ

作成日: 2026-09-17
更新日: 2026-10-18（CODH・国土地理院の位置参照に基づき5時点を再配置）

このメモは、`data/ogurike/feature-versions.geojson` の形状をどのように作成したかを記録する。形状は歴史資料の概略を現在のWGS84地図上に置いたもので、精密な境界・河道中心線・地籍を表さない。ビューアーで水域の変遷を追えるよう、国土交通省資料の変遷図①〜⑤に対応する5つの水域スナップショットを収録している。1885年・1933年の空間形状には公開データの形を利用し、他の年はその位置を参照して近畿地方整備局図の相対形状を配置している。

## 参照した資料

- 国土交通省近畿地方整備局「流域及び河川の概要について」p.2-21末尾–p.2-22、図2.2-1①〜⑤。1590年、1596年、1885年、1910年、1933年の図示スナップショットを参照した。図⑥（1953年・現在）は、このパイロットでは新しい歴史geometryを作らず、現在地図との比較対象として扱う。
- [水土の礎「京都府 巨椋池干拓事業」](https://suido-ishizue.jp/kokuei/kinki/Prefectures/2601/2601.html)。本文が示す東西約4km・南北約3km・約800haを、現在地図へ配置する際の規模感チェックに使った。掲載図「大池をめぐる村々」（`img/003.gif`）と「古代〜秀吉伏見築城以前／秀吉伏見築城〜江戸期の巨椋池」（`img/004.gif`・`img/005.gif`）は、湾入・周辺水域の読み取りを補助する比較資料であり、公開Featureの直接的な根拠にはせず測量図として座標化していない。
- 利用者共有の第三者画像（livedoor blog）は、上記の歴史図と見た目を比較する補助資料にとどめ、転載・トレース・権利のある画像の配布は行っていない。
- 京都府RDB「巨椋池」。地域、約794ha、干拓時期の補強に使った。掲載された地図画像のトレースや転載は行っていない。
- 京都市「巨椋池干拓碑」。碑の所在地と建立年の確認に使った。ページ本文、写真、碑文全文、掲載座標の転記は行っていない。
- [CODH「江戸末期湖沼データセット」](https://codh.rois.ac.jp/historical-gis/edo-lake/)、ID `26007`。1885年の主水域を置く空間上の参照形状として使用した。引用: `『江戸末期湖沼データセット』doi:10.20676/00000467`。作成: ROIS-DS人文学オープンデータ共同利用センター。CC BY 4.0。
- [国土地理院「地形分類（人工地形）」](https://github.com/gsi-cyberjapan/experimental_landformclassification)。`imports/gsi-artificial-land` の巨椋池周辺の干拓地feature `drained-01472`〜`drained-01480` を融合し、1933年版の空間上の参照形状として使用した。国土地理院コンテンツ利用規約に従う。地形分類は正確な干拓年を示さないため、1933年という時点は近畿地整図⑤に基づく。

CODH形状の重心は約 `(135.76293, 34.90329)`、GSI形状の融合重心は約 `(135.76157, 34.90316)` で、両者は近接する。手動復元形状の配置基準には2重心の中点 `(135.76225, 34.90322)` を使う。これらはデータ形状から計算した作業用アンカーであり、測量座標や歴史的位置の確定値ではない。

## 作成方法

- CODHの湖沼ID `26007` の形状を1885年版のPolygonに使用した。CODHが示すのは江戸末期〜明治初期の推定湖面であり、1885年の厳密な測量図ではない。1885年という年代と、図③の主水域として扱う判断は近畿地整図③に基づく。形状の座標を保持したままGeoJSONへ変換し、推定湖面を現在位置に置く参照形状として利用する。CODH形状は `imports/edo-lakes` からは除外し、`data/ogurike` だけに表示する。
- 1933年版のPolygonは、国土地理院の人工地形データのうち巨椋池干拓地に該当する `drained-01472`〜`drained-01480` を融合した形状である。約8km²の干拓地範囲を水域の空間上の代理形状として用いる。図⑤が示す1933年スナップショットの時点へ割り当てたものであり、GSIデータ自体が1933年の湖岸や正確な干拓年を示すわけではない。
- 1910年のPolygonは、近畿地整図2.2-1④を主資料として、北西側からの入り込み、東側の肩、南岸の複数の張り出しと湾入を残した概略面である。元の相対形状をCODHとGSIの各参照形状の重心の中間へ移し、面積が1885年と1933年の間になるよう拡大・縮小した。水土の礎の`img/003.gif`は池の輪郭や周辺水域の配置を照合する参考にしたが、画像を座標化・トレースしていない。別河道や中内池・二ノ丸池などの周辺水域は1910年の主水面へ混ぜず、holeや別Polygonも追加していない。
- 1590年・1596年のPolygonは既存の相対形状を保ち、CODHとGSIの参照形状の重心の中間へ平行移動した。1590年の宇治川代表線も同じ量だけ移動して主水面との接続関係を維持した。
- 1596年の宇治川LineStringは近畿地整図②に照らし、主湖面を南北に横断していた旧線から、湖の北～北東側を回る概略線へ修正した。資料が支持するのは「主湖面から分離し北側を通る」という相対的な関係であり、精密な河道中心線・堤防線形・西側接続位置ではない。座標は小数第3位程度に留める。水土の礎図005は作成者向けの比較資料として作成メモに記録し、正式な公開Evidenceには含めていない。
- 1590年のLineStringは図①が示す宇治川・流路網と主水面の接続関係を示す代表線であり、周囲の網状河道全体、支流数、正確な中心線は示さない。図①から個別枝の同定や座標位置を確定できないため、分岐線・島・砂州は追加していない。
- 水土の礎の東西約4km・南北約3km・約800haは形状の妥当性を確認する目安であり、面積から境界を逆算していない。資料図の縮尺・投影・湖岸線を精密に再現せず、座標の桁数や点数は測量精度を意味しない。資料図から読み取れない細部を発見したかのように解釈しない。
- 1596年のLineStringは図②が示す主湖面との分離を保つよう、移動後の水域北側へ引き直した。位置は湖面と交差しない相対関係を表す概略線で、精密な河道中心線・堤防線形・接続位置ではない。1590年と1596年の両方とも太閤堤・槇島堤の全長や現代の鉄道線との同一性を表現していない。
- 1942年のPointは、京都市ページの所在地を現在地図上の代表位置に丸めたものとし、小数第3位までに切り詰めた。著者用に確認した原座標、画像、碑文は公開ファイルへ保存していない。
- すべてのFeatureVersionは資料が示す単年スナップショットで、前後の年へ連続形状を補間していない。
- 形状を作成したのはChronomapであり、国土交通省・京都府・京都市がこのGeoJSONを作成したものではない。近畿地整資料を使ったFeatureVersionには、出典と手動加工の表示を付ける。
- CODHとGSIの出典を使った形状加工には、各Sourceの表示条件を適用し、公開Evidenceの `publicationBasis` を `open-license` とする。

## 採用しなかった資料と主張

- 京都府RDBの1917年地図画像、国土地理院旧版地図、第三者提供の航空写真は、権利・測量成果・転載条件を確定できないためトレースしていない。
- 1590年から1596年まで、1596年から1885年まで、1885年から1910年まで、1910年から1933年までの形状を補間していない。1953年（図⑥）の面も合成していないため、未収録の年を連続アニメーションとして解釈しない。
- 太閤堤・槇島堤の精密な線形、現代の鉄道線との一致、干拓前の全ての水路・島を主張していない。

このメモ自体はChronomapのオリジナルな作成記録であり、外部資料の文章・画像を再現するものではない。
