# 関ケ原古戦場・中山道パイロットの形状メモ

このパッケージの geometry は、岐阜県・関ケ原町の公開説明にある歴史的な関係を現在地図上で読むための概略復元です。行政境界、戦場全体、布陣、陣跡、街道中心線、宿場町の精密な境界を確定するデータではありません。

## 参照した資料

- [岐阜関ケ原古戦場記念館「岐阜関ケ原古戦場記念館について」](https://sekigahara.pref.gifu.lg.jp/about/)：1600年の関ケ原の戦い、東西交通の交差点という歴史文脈を読む根拠。
- [岐阜関ケ原古戦場記念館「石田三成コース」](https://sekigahara.pref.gifu.lg.jp/ishida-mitsunari/)：決戦地・陣跡などが関ケ原町内に分布することを読む根拠。個別史跡の座標は再現しない。
- [関ケ原町「関ケ原町過疎地域持続的発展計画」](https://www.town.sekigahara.gifu.jp/secure/6543/R7keikaku.pdf)：山間の交通要衝、中山道、関ケ原宿・今須宿の説明を読む根拠。

## 手作業で置いた座標と限界

- 関ケ原古戦場は、関ケ原盆地を読む代表 Point（136.47, 35.366）へ置いた。戦場全体、布陣、陣跡、戦線、行軍路の精密な位置・範囲ではない。
- 中山道は、東西の交通軸が関ケ原の山間を越える相対関係を少数頂点の LineString へ置いた。歴史的な街道中心線、道幅、宿駅間距離ではない。
- 関ケ原宿は、現在の関ケ原駅周辺を読む代表 Point（136.473, 35.366）へ置いた。宿場町の街区、屋敷、道幅、町域境界の精密な位置ではない。
- 公式資料には東軍・西軍や個別陣跡の説明があるが、行政的な勢力圏や陣営の確定Polygonを示す根拠ではないため、`polity`／`sphere-of-influence`／`boundary`は追加していない。
