# 常楽寺湊代表点形状作成メモ

滋賀県の安土城跡周辺資料は、常楽寺湊をかつて琵琶湖に面した港として説明し、安土城築城に伴う物資輸送・交易・軍事の拠点、琵琶湖の各港をつなぐ航路の拠点と位置づけています。この資料は港域を測量したGeoJSONや、1576年時点の正確な岸線・桟橋位置を提供するものではありません。

## 表示方法

`azuchijo:version:jyorakuji-port-1576` は、安土城との相対関係を地図上で読むための代表Pointです。座標は公開資料が示す安土山・城下町・西の湖／常楽寺湊の関係を少数値へ置き換えたChronomap独自の概略復元で、港域、岸線、船着場、航路の精密な位置を示しません。

表示期間は安土城築城開始から本能寺の変までの1576〜1582年頃です。常楽寺湊の中世から近世にわたる全期間や、豊浦港など周辺港の位置はこのFeatureVersionへ含めません。

外部資料の本文・図版・地図画像は再配布せず、SourceとEvidenceの引用メタデータだけを保持します。
