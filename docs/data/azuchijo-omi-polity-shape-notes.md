# 安土城・近江支配政治中枢形状作成メモ

このメモは、滋賀県の『近江戦国探訪ガイドブック』が説明する織田信長の近江支配、1576年の安土城築城、琵琶湖岸の拠点城郭網を、Chronomap上で「政治中枢」という意味に限定して表示するための作成記録です。資料は近江全域の行政境界や、信長の実効支配を測量した面を示していないため、正確な政治領域を復元したものではありません。

## 表示する2案

- `安土城中心案`: 安土城の所在する安土山を中心とする小さな概略Polygon。
- `安土城下町・湖岸を含む案`: 城下町と琵琶湖東岸との関係を含めて考える、少し広い概略Polygon。

2案は同じ仮説グループに属し、どちらにも優先順位を付けません。いずれも1576〜1582年頃という資料上の文脈に置いた低頂点形状です。

## 限界

- `polity` は、ここでは「政治主体が活動する中枢」を表す表示用の意味であり、近江全域を囲む行政境界・国境・軍事的な実効支配面ではありません。
- Polygonの頂点は資料の図版をトレースしたものではなく、安土城・城下町・湖岸の相対関係を説明するためのChronomap独自の概略復元です。
- 出典本文・図版・地図画像は複製せず、SourceとEvidenceの引用メタデータだけを保持します。
