# 香取海の標高タイル取込

`uv run chronomap-data import katori` は、国土地理院のPNG標高タイルから香取海の標高ベース推定を再生成し、`data/katori-sea`に5ファイルパッケージを書き出す。最初の取得は `.cache/raw/dem/katori-sea/` に保持され、同じキャッシュを使う再実行では取得済みの標高を再利用する。

## 取得と海判定

- 対象範囲は139.95〜140.95E、35.65〜36.25N。マスクはズーム13の標高タイルで作り、ズーム13で必要なデータがない場合はDEM10bのズーム12を補助に使う。
- 各タイルでDEM5a PNGを優先し、無ければDEM10b PNGを使う。両方のズーム13タイルが無い場合はDEM10bのズーム12タイルを取得する。取得不能タイルはNoDataと区別し、海判定に使わない。
- RGBを`x = R*65536 + G*256 + B`へ変換し、`x < 2^23`なら`x*0.01m`、`x = 2^23`なら欠測、`x > 2^23`なら`(x-2^24)*0.01m`とする。
- 700年4m、1200年3m、1600〜1654年2mを初期閾値とする。外洋seedはGSI住所検索の`千葉県銚子市川口町`応答緯度に対応する行だけに置き、同住所経度より東で最も右にある取得済みDEM欠測セルを使う。bboxを覆う完全なタイルモザイクで閾値以下のセルとDEM欠測セルを候補として4近傍で到達したセルのみを海とする。取得不能タイルは候補にしない。
- 面化後は指定bboxと鹿島灘・銚子沖の外洋カットで切る。カット後は銚子・霞ヶ浦・北浦・印旛沼・手賀沼・佐原の指定水域点を含む成分だけを残し、名前のある水域から離れたNoData成分を除く。印旛沼・手賀沼はPM指定点を起点にDEM低地成分（4m・5m）を3年代へ加えるが、DEMが高台を通る直線回廊を作ることを避け、資料が個別の水路を特定しないため主水域との接続は主張しない。佐原〜銚子の主水路は700年のDEM連結を保ち、1200年・1600年は佐原川口から主水域へ幅300m・700mの回廊を補う。補正幅は表示用モデルで、歴史上の河幅測量値ではない。約100mで簡略化した後にbboxで再度切る。補正後にも面積1ha未満の穴と断片を落とす。グリッド変換はWeb Mercatorメートル単位で、公開geometryはWGS84へ変換して小数第5位に丸める。銚子口の切断差は1200年・1600年だけ幅300mの回廊で補い、700年は4m閾値の下地を使う。

DEMタイルは更新され得る。キャッシュの無い初回取得には通信が必要で、出典の取得日を記録する。生成形状を過去の海岸線として確定的に解釈せず、利用前に[作成メモ](katori-sea-shape-notes.md)の不確実性を確認する。
