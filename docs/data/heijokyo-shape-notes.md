# 平城京パイロット形状作成メモ

作成日: 2026-09-18

形状は奈良市の平城京・朱雀大路の解説を参照してChronomapが作成した粗い独自再構成である。外部の本文・図版・地図画像を転載またはトレースしていない。

## 収録する形状

- `capital-710` は平城京の位置関係を示すために、奈良盆地北部へ置いた閉じた四角形である。都城の実測境界・外京を再現するものではない。
- `palace-710` は平城宮の代表位置を示すPointである。宮域、門、建物の正確な位置を表さない。
- `suzaku-avenue-710` は平城宮から南へ延びる朱雀大路の中心軸を示す2頂点のLineStringである。道路の全長、幅員、現地の史跡指定範囲を表さない。

全形状は`original-reconstruction`かつ`approximate`であり、古代の正確な境界・道路線形・未確認の河川を主張しない。奈良市の公式ページは引用メタデータの確認にのみ用い、本文・図版・地図画像を再現またはトレースしていない。
