# ADR 0001: 共通Webアプリと地域別データセット

Date: 2026-09-14

Status: Accepted

## Context

Chronomapは日本から開始し、中国史・世界史へ拡張する構想である。地域ごとに利用者体験と年代比較の基本機能を重複実装すると、修正と品質保証が分散する。

## Decision

日本・中国・世界でコードを分けず、共通Webアプリと地域別データセットを採用する。地域差は`Dataset`とデータ内容で表現し、共通の地図表示、年代絞り込み、出典表示を再利用する。

## Alternatives

- 地域ごとに別アプリを作る案は、独立した最適化はしやすいが、共通機能の保守を重複させるため採用しない。
- 地域専用コードを共通アプリ内に増やす案は、地域追加ごとの結合度を高めるため採用しない。
- ネイティブアプリを先行する案は、配布先を限定し、MVP検証の速度を下げるため採用しない。

## Consequences

地域データセットには共通の最小契約が必要になる。地域固有の表現が必要になった場合も、まずデータモデルの拡張で扱えるか検討する。
