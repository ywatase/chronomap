# ADR 0002: 静的クライアントMVP

作成日: 2026-09-14

Status: Accepted

## Context

巨椋池周辺を対象とするMVPでは、まず歴史データの表示、年代絞り込み、出典確認を検証する必要がある。運用サーバーを先に構築すると、検証対象ではない認証・運用・API保守の負担が増える。

## Decision

MVPはサーバーAPIを持たない静的クライアント構成とする。GeoJSONをブラウザで読み込み、クライアント側で検証・年代絞り込み・表示を行う。

## Alternatives

- PostGIS/APIは、更新頻度、検索・集計、アクセス制御、共同編集が静的公開の範囲を超えた時点で検討する。
- 専用タイルサーバーは、GeoJSONの配信量または描画量が性能目標を継続して満たせない時点で検討する。

## Consequences

データセットを静的に配布でき、MVPの構成を小さく保てる。一方で、データ量と描画性能を計測し、移行条件を満たした場合は構成を見直す。
