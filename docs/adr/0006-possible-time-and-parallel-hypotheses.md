# ADR 0006: 可能性優先の時間と並行仮説

Date: 2026-09-16

Status: Accepted

Superseded by: なし

## Context

歴史資料では開始・終了年、位置、形状、対象同定に幅や争いが残る。同一対象について相互に排他的な復元案がある場合、単一の確定表現に圧縮すると不確実性と根拠の差を隠してしまう。

## Decision

時間は天文学的年番号による開閉可能な境界とし、可能な活動期間を両端を含めて評価する。並行する復元案は、同一Entityで可能な期間が重なる複数のFeatureVersionを仮説グループとして併記する。仮説グループに手動の優先順位又はpreferredフラグを設けない。不確実性の4次元と根拠の要件は[歴史データ規範モデル](../data/model.md)に定める。

## Alternatives

- 年代を単一年又は単一の確度数値に丸める案は、期間幅と不確実性の種類を失うため採用しない。
- 最も有力と判断した一案だけを公開する案は、資料間の競合を見えなくするため採用しない。
- 仮説ごとに別のEntityを作る案は、同一対象についての並行表現を追跡できなくするため採用しない。

## Consequences

時間フィルタは、確定年だけでなく選択年と可能な期間の重なりを評価する。Metadata Panelは仮説ラベル、不確実性、根拠を併記し、利用者が並行案を識別できるようにする。
